On macOS, you can use SF Mono as your editor font in Zed with:

```json
{
  "buffer_font_family": ".AppleSystemUIFontMonospaced"
}
```

This doesn't show up in the suggested list of fonts, and it gives a "Value is not accepted" warning if you put it in, but it works!

If you know some Swift, you can find more font names with a script like:

```swift
import AppKit

let font = NSFont.monospacedSystemFont(
    ofSize: 14,
    weight: .regular
)

print(font.fontName) // .AppleSystemUIFontMonospaced
```
