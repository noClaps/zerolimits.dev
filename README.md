- [The Blog of Random](https://zerolimits.dev/blog) — A blog about the most random things you can think of.
- [Aperturic Focus](https://zerolimits.dev/gallery) — A website to showcase some cool photos I've taken.

## Build instructions

You'll need [Typst](https://typst.app) and [vips](https://libvips.org).

Clone the repository:

```sh
git clone https://github.com/noClaps/zerolimits.dev
cd zerolimits.dev
```

Run the build script:

```sh
make -j
```

This will build the site and place it in `dist/`.
